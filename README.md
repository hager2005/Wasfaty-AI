# Wasfaty-AI
 مساعدة المستخدمين على متابعة وجباتهم اليومية. توفير معلومات غذائية تقديرية بطريقة سهلة. زيادة الوعي بالعادات الغذائية. الاستفادة من الذكاء الاصطناعي في تطبيقات الحياة اليومية. تشجيع المستخدم على الاهتمام بتنظيم وجباته. ✨ رؤية المشروع Wasfaty AI مش مجرد تطبيق للتعرف على الطعام، لكنه محاولة لتوظيف الذكاء الاصطناعي في تسهيل متابعة التغذية وجعل المعلو
